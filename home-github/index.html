기억의 궁전 지도

기억의 궁전이란 체계 시스템을 만드는 것이다. 분류화 하고 체계화 하고 누적적으로 지식을 축적하는 것. 9_Brain Science › Memory › 기억의 궁전
  • 8시트 (전시실)
  • 86탭 (방)
  • 303열 (선반)
  • 9,749줄 (카드)

찾는 순서

  1. 이 지도에서 시트와 탭을 좁힌다. 열 머리글이 곧 주제다.
  2. notes/atman/ 사본을 grep 으로 찾는다. 탭은 ##, 열 머리글은 ###, 셀은 글머리 한 줄이다.
  3. 사본이 하루보다 오래됐으면 memory-palace-sync 로 갱신한다 (약 15초). 매일 00:30 KST 에 cron 이 돌린다.
  4. 원본을 고쳐야 하면 각 전시실 머리의 링크로 구글 시트를 연다.

카드마다 방 이름, 선반(열 머리글)과 그 선반의 줄 수를 적었다. 카드 아래 초록 띠는 같은 시트 안에서 그 방이 차지하는 비중이다. 흐린 선반은 아직 비어 있는 열이다.

명령

# 주제로 찾기 (탭·열 머리글 우선)
grep -n '^##' notes/atman/*.md | grep 도파민

# 본문까지 찾기
grep -rn '한계효용' notes/atman/

# 사본 갱신
~/.claude/scripts/memory-palace-sync

# 오늘의 카드 (무작위 한 장 + 이어지는 카드 2~3장)
~/.claude/scripts/daily-card-send
